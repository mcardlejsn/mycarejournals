Installing directly from this website

A few Android taps.
No store account needed.

These are standard signed Android APK files. Android may ask you to approve installation from your browser the first time you download one.

1
Choose an app

Tap its Download APK button and let the file finish downloading.

2
Open the downloaded APK

Your browser or Files app will ask whether you want to install it.

3
Allow this source if prompted

Android may ask you to permit app installation from that browser. This setting can be turned off again afterward.

4
Tap Install

Android and Google Play Protect may scan the file before installation completes.

Safety note: Download these apps only from mycarejournals.com or the official mcardlejsn/mycarejournals GitHub releases page. Never install a copy sent by an unknown person.
