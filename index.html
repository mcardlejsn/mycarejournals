Direct Android installation

A few taps.
No account needed.

Medication Routine is currently available as a standard signed Android APK. Android may ask you to approve installation from your browser the first time.

1
Download the APK

Use the Medication Routine download button above and let the file finish downloading.

2
Open the downloaded file

Your browser or Files app will ask whether you want to install it.

3
Allow this source if prompted

Android may ask you to permit installation from that browser. You can turn the permission off again afterward.

4
Tap Install

Android and Google Play Protect may scan the file before installation completes.

Safety note: Download these apps only from mycarejournals.com or their official Google Play listings when available. Never install a copy sent by an unknown person.
